# Contributing to HoTTY

Thank you for your interest in HoTTY!

HoTTY is primarily a personal project developed for specific use cases. Please note the following policies regarding contributions:

## Contribution Policy

- **No Pull Requests**: We do not accept Pull Requests (PRs) at this time.
- **Issues are Welcome**: If you find a bug or have a feature request, please feel free to open an **Issue**.
- **Forks**: As HoTTY is licensed under **GPLv3**, you are free to fork the repository and modify it according to the license terms.

---

# HoTTY への貢献について

HoTTY に興味を持っていただきありがとうございます！

HoTTY は基本的に個人のユースケースに合わせて開発しているプロジェクトです。貢献に関しては、以下のポリシーを適用しています。

## 貢献ポリシー

- **プルリクエスト（PR）について**: 現在、プルリクエストの受け付けは行っていません。
- **不具合・要望について**: バグの報告や新機能の要望などは、**Issues** で受け付けています。お気軽に投稿してください。
- **フォークについて**: HoTTY は **GPLv3** ライセンスで公開されています。ライセンスの条項に従い、自由にフォークして変更を加えることができます。
