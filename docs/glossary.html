Glossary of Terms

Key terms and concepts used in HoTTY.

Connection SSH (Secure Shell)
A cryptographic network protocol for secure communication over an unsecured network. HoTTY supports SSH connections with public key and password authentication, host key verification via known_hosts, and KeepAlive to prevent idle disconnects.
Connection Telnet
A legacy network protocol for bidirectional text-based communication. Unlike SSH, Telnet does not encrypt traffic. HoTTY supports Telnet connections with optional username/password authentication and KeepAlive.
Connection Serial Connection
A communication method using a serial port (COM port) to connect to devices such as routers, switches, and embedded systems. Configuration includes baud rate, data bits, stop bits, parity, and flow control.
Connection Baud Rate
The speed of data transmission over a serial connection, measured in bits per second (bps). Common values include 9600, 19200, 38400, 57600, and 115200. Must match the setting on the target device.
Connection WSL (Windows Subsystem for Linux)
A Windows feature that lets you run Linux distributions natively. HoTTY automatically discovers installed WSL distributions and allows you to open them as terminal sessions.
Connection Local Shell
A terminal session running a local command interpreter (e.g., PowerShell, Command Prompt, or Git Bash) directly on your Windows machine without any network connection.
Connection KeepAlive
A mechanism that sends periodic packets to prevent an idle connection from being dropped by firewalls or the remote server. HoTTY supports SSH and Telnet KeepAlive with configurable intervals.
Connection Jumpbox (Jump Host / Bastion Host)
An intermediary server used to access devices in a private network. HoTTY supports jumpbox chaining, allowing you to connect through one or more jump hosts to reach a final destination.
AI AI Monitor
A HoTTY feature that captures terminal output and sends it to the AI for real-time analysis. You can request explanations, root cause analysis, or fix suggestions using predefined prompts.
AI Interactive Investigation
An AI workflow where the AI proactively proposes diagnostic commands, HoTTY executes them on the terminal, captures the output, and feeds it back to the AI for continued analysis — all automatically.
AI Execute Block
A special code block (```execute) used by the AI to propose commands for execution on the terminal. When the user approves, HoTTY runs the command and captures the output for follow-up analysis.
AI Gemini
Google's family of large language models. HoTTY integrates with Gemini via Google AI Studio or Vertex AI to provide intelligent terminal assistance. Available models are auto-discovered from your API key.
AI AI Provider
The AI service backend used for chat and analysis. HoTTY supports multiple providers: Google AI Studio (Gemini), Vertex AI, Anthropic (Claude), and OpenAI. Each provider requires its own API key or authentication.
Terminal Terminal Emulator
Software that replicates the functionality of a traditional hardware terminal, providing a text-based interface for interacting with a local or remote system. HoTTY is a modern terminal emulator built with xterm.js.
Terminal ANSI Escape Sequences
Special character sequences used to control text formatting, colors, and cursor positioning in terminals. Examples include bold text, color changes, and screen clearing. HoTTY fully supports ANSI/VT100 escape codes.
Terminal Encoding
The character set used to interpret bytes as text. HoTTY supports multiple encodings (e.g., UTF-8, Shift_JIS, EUC-JP) per session, ensuring correct display of text from systems using different character sets.
Terminal Session
An active connection to a local or remote system, displayed as a tab in HoTTY. Each session maintains its own terminal state, encoding, font settings, and color scheme. Sessions can be organized across multiple panes.
Terminal Session Log
A recorded log of all terminal input and output during a session. HoTTY saves logs with millisecond-precision timestamps and provides a built-in Log Viewer for reviewing them.
Terminal Terminal Marker
Colored vertical lines displayed on the right edge of the terminal that visually distinguish command prompts from their output. Red/orange markers indicate where you typed a command; blue markers indicate the resulting output. Click a marker to select the entire block, or right-click to ask AI about that specific output.
Terminal Host Tree
A hierarchical tree structure for organizing saved connection profiles (hosts) into folders. Supports drag-and-drop reordering, import/export of configurations, and quick-connect by double-clicking a host entry.
Security Known Hosts
A file that stores the public keys of SSH servers you have connected to. HoTTY manages known_hosts automatically, warning you if a server's key has changed (which could indicate a man-in-the-middle attack).
Security DPAPI (Data Protection API)
A Windows API for encrypting and decrypting data using credentials tied to the current user account. HoTTY uses DPAPI to securely store sensitive credentials like passwords and API keys.
Security Sandbox
A security mechanism that isolates running processes to limit their access to the system. HoTTY runs within Electron's sandboxed environment with contextIsolation enabled to prevent untrusted code from accessing system resources.
Security CSP (Content Security Policy)
A security standard that helps prevent cross-site scripting (XSS) and other code injection attacks by specifying which content sources are trusted. HoTTY enforces CSP to protect the renderer process.
UI Grid Layout
HoTTY's multi-pane workspace system with Top Bar, Bottom Bar, Left Sidebar, and Right Sidebar. You can drag the intersection point where four panes meet to resize all panels simultaneously. Layout is auto-saved.
UI Theme
A set of colors, fonts, and visual styles applied to the entire HoTTY interface. Three built-in themes (Dark, Medium, Light) are provided, plus a Custom mode for full control over every UI color using the Visual Theme Creator.
UI Pane
A subdivided area of the HoTTY window that holds one or more tabbed sessions. Panes can be positioned as a main area, sidebar, or bar, allowing you to view multiple sessions side by side.
UI Log Viewer
A built-in HoTTY feature that opens saved session logs as dedicated read-only tabs. Provides timestamp display, text search, and ANSI color rendering for reviewing past sessions.
