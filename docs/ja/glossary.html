用語集

HoTTYで使用される主要な用語と概念の一覧です。

接続 SSH (Secure Shell)
安全でないネットワーク上で暗号化された通信を行うためのプロトコル。HoTTYは公開鍵認証・パスワード認証、known_hostsによるホスト鍵検証、アイドル切断を防ぐKeepAliveに対応しています。
接続 Telnet
双方向テキスト通信のためのレガシーネットワークプロトコル。SSHとは異なり通信は暗号化されません。HoTTYはユーザー名/パスワード認証とKeepAliveに対応したTelnet接続をサポートしています。
接続 シリアル接続
シリアルポート（COMポート）を使用してルーター、スイッチ、組み込みシステムなどのデバイスに接続する通信方式。ボーレート、データビット、ストップビット、パリティ、フロー制御の設定が可能です。
接続 ボーレート
シリアル接続におけるデータ転送速度で、ビット毎秒（bps）で測定されます。一般的な値は9600、19200、38400、57600、115200です。接続先デバイスの設定と一致させる必要があります。
接続 WSL (Windows Subsystem for Linux)
WindowsでLinuxディストリビューションをネイティブに実行できる機能。HoTTYはインストール済みのWSLディストリビューションを自動検出し、ターミナルセッションとして開くことができます。
接続 ローカルシェル
ネットワーク接続なしに、Windowsマシン上でローカルのコマンドインタープリター（PowerShell、コマンドプロンプト、Git Bashなど）を直接実行するターミナルセッション。
接続 KeepAlive
ファイアウォールやリモートサーバーによるアイドル接続の切断を防ぐために、定期的にパケットを送信する仕組み。HoTTYはSSHとTelnetのKeepAliveに対応し、送信間隔を設定できます。
接続 Jumpbox （踏み台サーバー / Bastion Host）
プライベートネットワーク内のデバイスにアクセスするための中継サーバー。HoTTYはジャンプボックスチェーンに対応しており、1台以上の踏み台を経由して最終的な接続先に到達できます。
AI AIモニター
ターミナル出力をキャプチャしてAIに送信し、リアルタイムで分析するHoTTYの機能。「説明」「原因調査」「修正提案」などの定義済みプロンプトで即座に解析を依頼できます。
AI インタラクティブ調査
AIが調査コマンドを自発的に提案し、HoTTYがそれをターミナルで実行、出力をキャプチャしてAIにフィードバックし、分析を継続するワークフロー。すべて自動で行われます。
AI Executeブロック
AIがターミナルでの実行を提案するための特殊なコードブロック（```execute）。ユーザーが承認するとHoTTYがコマンドを実行し、出力をキャプチャして後続の分析に使用します。
AI Gemini
Googleの大規模言語モデルファミリー。HoTTYはGoogle AI StudioまたはVertex AIを経由してGeminiと連携し、インテリジェントなターミナルアシスタンスを提供します。利用可能なモデルはAPIキーから自動検出されます。
AI AIプロバイダー
チャットと分析に使用されるAIサービスのバックエンド。HoTTYは複数のプロバイダーに対応しています：Google AI Studio（Gemini）、Vertex AI、Anthropic（Claude）、OpenAI。各プロバイダーには固有のAPIキーまたは認証が必要です。
ターミナル ターミナルエミュレーター
従来のハードウェアターミナルの機能を再現し、ローカルまたはリモートシステムとのテキストベースのインターフェースを提供するソフトウェア。HoTTYはxterm.jsで構築されたモダンなターミナルエミュレーターです。
ターミナル ANSIエスケープシーケンス
ターミナルでのテキストの書式設定、色の変更、カーソル位置の制御に使用される特殊な文字列。太字、色の変更、画面クリアなどが含まれます。HoTTYはANSI/VT100エスケープコードを完全にサポートしています。
ターミナル エンコーディング
バイト列をテキストとして解釈するための文字セット。HoTTYはセッションごとに複数のエンコーディング（UTF-8、Shift_JIS、EUC-JPなど）に対応しており、異なる文字セットを使用するシステムからのテキストを正しく表示できます。
ターミナル セッション
ローカルまたはリモートシステムへのアクティブな接続で、HoTTYではタブとして表示されます。各セッションは独自のターミナル状態、エンコーディング、フォント設定、配色を保持し、複数のペインにわたって整理できます。
ターミナル セッションログ
セッション中のすべてのターミナル入出力を記録したログ。HoTTYはミリ秒精度のタイムスタンプでログを保存し、内蔵のログビューアーで確認できます。
ターミナル ターミナルマーカー
ターミナルの右端に表示される色付きの縦線で、コマンドプロンプトとその出力を視覚的に区別します。赤/オレンジのマーカーはコマンドを入力した位置を、青のマーカーは実行結果の出力を示します。マーカーをクリックするとブロック全体を選択でき、右クリックでその出力についてAIに質問できます。
ターミナル ホストツリー
保存された接続プロファイル（ホスト）をフォルダーで階層的に整理するツリー構造。ドラッグ＆ドロップによる並べ替え、設定のインポート/エクスポート、ダブルクリックによるクイック接続に対応しています。
セキュリティ Known Hosts
接続したSSHサーバーの公開鍵を保存するファイル。HoTTYはknown_hostsを自動管理し、サーバーの鍵が変更された場合（中間者攻撃の可能性）に警告を表示します。
セキュリティ DPAPI (Data Protection API)
現在のユーザーアカウントに紐づけられた資格情報を使用してデータを暗号化・復号化するWindows API。HoTTYはパスワードやAPIキーなどの機密情報を安全に保存するためにDPAPIを使用しています。
セキュリティ サンドボックス
実行中のプロセスを分離してシステムへのアクセスを制限するセキュリティ機構。HoTTYはElectronのサンドボックス環境内でcontextIsolationを有効にして実行され、信頼されないコードによるシステムリソースへのアクセスを防止します。
セキュリティ CSP (Content Security Policy)
クロスサイトスクリプティング（XSS）やその他のコードインジェクション攻撃を防ぐために、信頼されるコンテンツソースを指定するセキュリティ標準。HoTTYはレンダラープロセスを保護するためにCSPを適用しています。
UI グリッドレイアウト
トップバー、ボトムバー、左サイドバー、右サイドバーを備えたHoTTYのマルチペインワークスペース。4つのペインが交差するポイントをドラッグして、すべてのパネルを同時にリサイズできます。レイアウトは自動保存されます。
UI テーマ
HoTTYインターフェース全体に適用される色、フォント、ビジュアルスタイルのセット。3つのビルトインテーマ（ダーク、ミディアム、ライト）に加え、ビジュアルテーマクリエイターですべてのUI色を自由にカスタマイズできるCustomモードがあります。
UI ペイン
1つ以上のタブ付きセッションを保持するHoTTYウィンドウの分割エリア。メインエリア、サイドバー、バーとして配置でき、複数のセッションを並べて表示できます。
UI ログビューアー
保存済みのセッションログを専用の読み取り専用タブとして開くHoTTYの組み込み機能。タイムスタンプ表示、テキスト検索、ANSIカラーレンダリングにより過去のセッションを確認できます。
