Everything You Need in One Terminal

From legacy network devices to modern cloud servers — HoTTY handles every connection type with a flexible workspace layout.

🔌
Multi-Protocol Support
Connect to anything — from modern cloud servers to legacy Cisco hardware. WSL distributions are auto-discovered.
SSH Telnet Serial WSL Local
⊞
Advanced Grid Layout
Flexible multi-pane workspace with Top/Bottom Bars and Left/Right Sidebars. Drag pane junctions to resize all 4 panels at once. Layout is saved automatically.
🎨
Visual Theme Creator
Three built-in themes (Dark, Medium, Light) plus a fully customizable mode. Fine-tune every UI color interactively — no JSON editing required.
📡
Session Management
Persistent fonts, encoding, and color settings across sessions. SSH & Telnet KeepAlive prevents idle disconnects. Passwords stay in memory only.
📋
Log Viewer
Open saved session logs directly inside HoTTY as a dedicated tab. Millisecond-precision timestamps for precise debugging.
🔒
Security First
Sandboxed Electron execution, path traversal protection, IPC input validation, and Content Security Policy. Known_hosts management built in.

An AI That Works Right Beside You

HoTTY is more than a terminal. With Google Gemini built in, your AI assistant watches, understands, and acts on your terminal output in real time.

  • 👁
    Watch Gemini Monitor terminal output and request instant analysis — Explain, Research, or Suggest Fixes.
  • 🔍
    Interactive Investigation AI proactively proposes commands, captures results, and continues analysis automatically.
  • 💬
    Free Format Questions Right-click selected text to ask custom questions directly from the terminal context menu.
  • ⚡
    Dynamic Model Selection Automatically discovers all available Gemini models from your API key.
Gemini Chat
U
Nginx just failed. Can you investigate?
G
I'll check the system logs to identify the cause of the Nginx failure.
```execute
journalctl -u nginx --since "10 min ago" --no-pager | tail -30```
U
[output captured — analyzing...]
G
Found it — port 80 is already in use by Apache. Let me stop it and restart Nginx.
```execute
systemctl stop apache2 && systemctl start nginx```
