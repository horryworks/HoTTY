# HoTTY

**AI統合型 高機能ターミナルエミュレータ** — Rust (Tauri v2) + React + TypeScript で構築。

HoTTY は、SSH、Telnet、シリアル、WSL、ローカルシェル (cmd / PowerShell / Git Bash) 接続に対応した Windows 向けマルチプロトコルターミナルエミュレータです。マルチペインレイアウト、統合ユーティリティツール、テーマ機能、セッションログなどを備えています。

> これは [HoTTY (Electron版)](https://github.com/horryworks/HoTTY) を Tauri v2 でフルスクラッチで書き直したバージョンです。メモリ効率とパフォーマンスが大幅に向上しています。

## 機能

### マルチプロトコル接続
- **SSH** — ホスト鍵検証、秘密鍵認証、アルゴリズム設定対応
- **Telnet** — エンコーディング対応 (UTF-8, Shift_JIS, EUC-JP)
- **シリアル** — ボーレート、データビット、パリティ、ストップビット、フロー制御の設定対応
- **WSL** — ディストリビューション選択対応
- **ローカルシェル** — cmd、PowerShell、Git Bash

### マルチペインレイアウト
- 柔軟なグリッドレイアウト: 1x1, 1x2, 2x1, 2x2, 2x3, 3x2
- 四辺 (左・右・上・下) に折りたたみ可能なサイドバー
- キーボードによるペインフォーカス移動 (`Ctrl+Tab` / `Ctrl+Shift+Tab`)
- ドラッグ＆ドロップによるタブの並べ替えとペイン割り当て
- セッションタブとフィーチャーペインタブの管理
- **マルチウィンドウ** — 1 つのプロセスで複数のウィンドウを開ける (新しいウィンドウ / `Ctrl+Shift+N`)。各ウィンドウは独自のペインとセッションを持ち、設定・テーマ・ホストツリー・ブックマークはすべてのウィンドウで共有・同期

### 統合ユーティリティツール
- **ログビューア** — セッションログファイルと AI チャット履歴の閲覧・表示。ペイン内検索 (`Ctrl+F`) に対応し、正規表現・大文字小文字の区別・一致した行のみの表示が利用可能
- **Pingモニター** — 複数ターゲットの監視 (間隔設定可能)
- **インターフェーストラフィック** — スイッチやルーターのインターフェースカウンター (bps / pps / エラー / 破棄数) を SNMP v2c・v3 でリアルタイム表示。インターフェースの自動検出、ソート・絞り込み可能な一覧、対応機器では 64 ビット `ifXTable` カウンター、認証情報の DPAPI 暗号化保存に対応
- **ファイルサーバー** — ネットワーク機器 (Cisco など) へのファームウェア/設定アップロード用の組み込み TFTP・SFTP サーバー (共有はフォルダー内に限定、Windows ファイアウォール検出付き)
- **Web ブラウザー** — ネットワーク機器の Web 管理画面向けの組み込みブラウザーペイン (Edge WebView2)。New Session → Web からフォルダー整理されたブックマークで開け、ログインセッションを保持し、パスワードの保存/自動入力に対応。ページごとのズームにも対応し、閲覧データ（Cookie・キャッシュ・履歴・パスワード）も任意に削除できます

### テーマ・外観
- 組み込みテーマ: Dark、Medium、Light
- CSS変数によるカスタムテーマ対応
- フォントファミリー・フォントサイズの設定

### 多言語対応
- アプリ内の **表示言語** セレクタ (設定 → 一般) による UI の多言語化
- 8 言語対応: English、日本語、简体中文、繁體中文、한국어、Русский、Español、Français — 再起動なしで即座に切り替え
- AI の回答は既定で表示言語に追従（AI チャットペインで個別に上書き可能）

### セキュリティ・認証情報
- Windows DPAPI による認証情報の暗号化
- SSH ホスト鍵検証 (フィンガープリント表示)
- クリップボード内容の貼り付け確認モーダル

### セッション管理
- セッションごとのエンコーディング選択
- 端末サイズの固定 — ログイン時に端末幅を確定し以降のサイズ変更を無視する機器 (Huawei USG/VRP など) 向けに、接続時にネゴシエートした幅へ端末を固定。既定では自動判定し、接続ごと・タブごとに上書き可能
- セッションログのファイル出力 — ターミナル出力は `.txt`、AI チャットの会話は同じフォルダに Markdown 形式で保存
- 接続ホストツリーのエクスポート・インポート (暗号化 .htree 形式)

### AI 統合
- マルチプロバイダー対応: Google AI Studio (Gemini)、Vertex AI、Anthropic (Claude)、OpenAI (GPT)
- AI チャットペイン — ストリーミングレスポンス、ペルソナ、トークンコスト追跡、色分けされた複数の並列会話
- 画像添付 — 画像対応モデルで、画像を貼り付け・ドラッグ＆ドロップ・添付して AI チャットのメッセージに含められます
- 回答言語 — **Auto** はアプリの表示言語に追従。特定の言語への固定も可能で、設定はすべてのウィンドウで共有され、進行中の会話にも適用されます
- Ask AI — ターミナル出力を選択して右クリックし、質問を入力して（選択範囲とともに）AI チャットに送信
- インタラクティブモード — AI がターミナルコマンドを提案・実行 (管理可能なホワイトリスト / ブラックリスト + AI の安全性分類付き)
- ウォッチモード — 1 つの AI チャットの会話で複数のターミナルを同時に監視でき、AI が提案するコマンドは適切なターミナルへ自動振り分け。キャプチャした出力を AI に送信して分析
- ウィンドウ間リンク — AI チャットを別ウィンドウで実行中のターミナルにリンク
- AI にターミナルのデータを初めて送信する前に、一度だけデータ送信に関するお知らせを表示 (設定 → AI で再確認可能)
- カスタマイズ可能なペルソナ

### その他の機能
- Google Cloud インスタンス向け GCE IAP トンネル
- SSH アルゴリズム設定 (KEX, 暗号, MAC, ホスト鍵)
- システムフォント検出
- コンテキストメニュー
- デバッグログ管理
- サードパーティライセンスビューア (設定 → 情報)

## 開発

### 前提条件
- [Node.js](https://nodejs.org/) (LTS)
- [Rust](https://www.rust-lang.org/tools/install) (1.77.2+)
- [Tauri CLI](https://v2.tauri.app/start/prerequisites/)

### コマンド

```bash
npm install              # フロントエンド依存パッケージのインストール
npm run tauri:dev        # 開発サーバー + Tauri ウィンドウの起動
npm run tauri:build      # インストーラー付きプロダクションビルド
npm run test             # フロントエンドテスト実行 (Vitest)
npm run lint             # ESLint 実行
cd src-tauri && cargo test   # バックエンドテスト実行
cd src-tauri && cargo clippy # Clippy リント実行
```

## プライバシー / データの取り扱い

HoTTY はローカルで動作し、テレメトリ・解析・利用データを**一切収集しません**。
HoTTY 自身が行うネットワーク通信は、GitHub Releases API への任意のアップデート
確認のみです。

**AI 機能**（AI チャット、Ask AI、インタラクティブモード、ウォッチモード）を使用
すると、設定した第三者 AI プロバイダー（Google Gemini / Vertex AI、Anthropic、
OpenAI）へ、**ユーザー自身の API キー**を用いて、そのプロバイダーの利用規約・
プライバシーポリシーの下でデータが送信されます。

- **送信される内容：** 入力したメッセージ、および Ask AI 使用時やウォッチモード
  有効時にはセッションから取得した端末出力・コマンド。
- **送信のタイミング：** AI 機能を明示的に呼び出したときのみ。HoTTY が端末を
  常時ストリーミングすることはありません。
- **マスキング：** 既知のシークレットパターンはログ上でデフォルトでマスクされ
  ますが、チャットメッセージに自分で貼り付けたテキストはそのまま送信されます。
  AI プロンプトに認証情報を貼り付けないでください。

AI 機能を初めて使用する際、上記を要約した同意ダイアログが一度だけ表示されます。
認証情報・API キーは Windows DPAPI により暗号化して保存されます。
