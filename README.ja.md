# HoTTY v1.0.4 - AI統合型高機能ターミナルエミュレータ

[English](README.md) | [日本語]

**現在のバージョン: v1.0.4**

HoTTY は、Electron、React、および TypeScript で構築された、モダンで高性能なターミナルエミュレーターです。高度なウィンドウ管理とカスタマイズオプションを備え、シームレスなターミナル体験を提供します。

## 主な機能

- **マルチプロトコル対応**: SSH, Telnet, SerialPort, WSL, **Windowsローカルシェル (CMD/PowerShell)**, そして **Git Bash** に対応。
    - **ジャンプボックス（踏み台ホスト）**: SSH および Telnet 接続を中間の SSH ジャンプボックスを経由してルーティング可能。ホストツリーで任意の SSH ホストをジャンプボックスとして指定し、ターゲットホストに割り当てることでトンネル接続を実現。
    - **GCE IAP トンネル**: Google Compute Engine VM に Identity-Aware Proxy (IAP) 経由で接続。VM をパブリックインターネットに公開する必要がありません。gcloud CLI と連携し、GCP プロジェクト・ゾーン・インスタンスのオートコンプリートに対応。
    - **WSL 統合**: インストール済みの Linux ディストリビューション（Ubuntu, Debian等）を自動検出し、ダイレクトに接続可能。
    - **Git Bash**: Git Bash のインストールを自動検出し、インタラクティブなログインシェルセッションを提供。
    - **幅広い SSH 互換性**: DH Group 1/14, 3DES, CBC 暗号、およびすべての主要な Key Exchange アルゴリズムをサポート。最新のサーバーから Cisco 等のレガシーなネットワーク機器まで対応。
- **高度なグリッドレイアウト**: 
    - **トップ/ボトムバー** と **左右サイドバー** を組み合わせた柔軟なワークスペース。
    - **レイアウトの保存と復元**: 再起動時に前回の構成（バーのサイズ、表示状態、グリッド比率）を自動的に復元します。
    - **スマートリサイズ**: ウィンドウサイズに合わせて比率を維持するパーセントベースのレスポンシブデザイン。
    - **ツールバー位置**: 設定 > 外観 からサイドバーを左右に切り替え可能。
    - タブのドラッグ＆ドロップによるペインの再構成。
    - 直感的なリサイズ操作。4つのペインが重なる十字部分をドラッグすることで、縦横同時にリサイズできる **2Dインターセクション・リサイズ** を搭載。
- **カスタマイズ性**:
    - **テーマ**: **Dark**、**Medium**、**Light** の3つのプリセットに加え、**Custom** モードでは配色を自由に設定可能。
    - **カスタムテーマクリエイター**: すべての UI カラーをビジュアルエディタで直感的に調整し、オリジナルテーマとして保存できます。JSON の手動編集は不要。
    - **高度な設定管理**: テーマ (`themes.json`) や SSH アルゴリズム (`ssh_algorithms.json`) は外部ファイルとして管理され、ユーザーデータフォルダ（`%APPDATA%/HoTTY`）から直接編集可能。
    - **ビジュアルの刷新**: 新しい黒い「H」ロゴを採用し、各テーマでの視認性を最適化しました。
    - **高度な背景設定**: 単色表示に加え、画像（SVG/PNG/JPG等）のタイル表示や、**標準のロゴ背景（Default）**をサポート。
    - **ファイル選択**: 内蔵のエクスプローラー連携により、PC内の画像を簡単に背景として選択可能。

- **セッション管理**:
    - フォント、エンコーディング、配色設定を自動的に保存・復元。
    - **SSH KeepAlive**: タイムアウトによるSSH切断を防止。
    - **Telnet KeepAlive**: TCP Keepalive + Telnet NOP の2層方式で、Telnetセッションのアイドル切断を防止。設定 > Telnet から設定可能。
    - **セキュアな認証情報管理**: SSHパスワードはメモリ内にのみキャッシュされ、ディスクには一切保存されません。「パスワード表示」トグルで必要に応じて保存済みパスワードを確認可能。
    - **ログビューアー**: 保存済みのセッションログファイルを HoTTY 内の専用タブで直接開いて閲覧可能。テキスト/正規表現による検索、Ctrl+F で検索欄にフォーカス、Refresh ボタンでファイルの再読み込みをサポート。
- **AI 統合**:
    - **マルチプロバイダー対応**: 設定 > AI から使用するバックエンドを選択可能 — **Google Gemini** (Google AI Studio)、**Vertex AI** (Google Cloud)、**OpenAI**、**Anthropic** に対応。
    - **AI Chat**: AI アシスタントペインを内蔵。インタラクティブなターミナルサポートが可能。
    - **インタラクティブ調査**: AI が自発的に調査コマンドを提案し、その実行結果を自動でキャプチャして解析を継続します。
    - **AI Monitor (出力監視)**: ターミナルの出力を監視・記録し、状況に応じたプロンプト（説明、原因調査、修正提案など）でAIに一括解析を依頼可能。
    - **スマート・チャットスクロール**: AI の回答が長い場合に、自動的に回答の先頭が表示されるよう調整。
    - **フリーフォーマット質問**: ターミナル上のコンテキストメニューから、選択したテキストに対して自由に質問を作成・送信可能。
    - **ペルソナ別 Ask コマンド**: AI ペルソナごとに独自の Ask AI コマンドセットを設定可能。ペルソナに応じたクイックアクションを実現。
    - **ダイナミックモデル**: 選択した AI プロバイダーから利用可能なモデルリストを自動取得。
    - **コマンド実行の安定性向上**: AI のレスポンス解析を改善し、ターミナルへのコマンド送信をより確実に実行。
- **セキュリティと信頼性**:
    - **パス・トラバーサル保護**: `media://` プロトコルの検証によるセキュリティ強化。
    - **サンドボックス実行**: Electron のサンドボックスモードによる安全な実行。
    - **XSS 対策**: AI チャットの出力を DOMPurify でサニタイズし、クロスサイトスクリプティング攻撃を防止。
    - **クリーン・アンインストール**: アンインストール時にすべてのユーザーデータを削除するオプション。
- **テキストエディター**: 内蔵テキストエディターペイン（**⊞** Features メニュー → **Text Editor** から開けます）。マルチタブ編集、エンコーディング選択（UTF-8、ASCII、Latin-1）と改行コード表示（LF/CRLF）に対応したファイルの開く・保存、検索 & 置換、行ジャンプ、折り返し行を正確に反映したビジュアル行番号、改行コードの可視化表示（View メニューから切替可能）、コマンドライン引数からのファイル関連付けをサポート。
- **ファイルエクスプローラー**: 内蔵ファイルブラウザペイン（**⊞** Features メニュー → **File Explorer** から開けます）。ドライブとディレクトリをツリー構造で閲覧、フォルダの展開/折りたたみ（遅延読み込み）、隠しファイルの表示切替、ダブルクリックでテキストエディターに直接ファイルを開く機能を搭載。大量ファイルでも仮想スクロールによるスムーズなパフォーマンスを実現。
- **Ping Monitor（Ping監視）**: 複数ホストの ICMP Ping を同時に監視するペインを内蔵。1秒～60秒の間隔設定、リアルタイムの RTT・TTL 表示、ステータスインジケーター、CSV ログ出力に対応。
- **アップデート通知**: 起動時に GitHub 上の新リリースを自動チェック。新バージョンが公開されている場合、非ブロッキングなバナーで通知（Pre-release は対象外）。**Skip this version** または **Never Notify** ボタンで通知の表示方法を制御可能。**設定 > About** タブにも更新があるときはダウンロードリンクが表示されます。
- **モダンな技術スタック**: パフォーマンスと安定性のために Electron、React、Vite を採用。

## HoTTY のコア・コンセプト：AI とターミナルの融合

HoTTY は単なるターミナルではなく、AI が「あなたの隣で動作を見守るパートナー」になることを目指しています。

- **「見る」AI**: `AI Monitor` を有効にすると、AI はターミナルの出力を常に把握します。エラーが出た瞬間に「何が起きたか」を尋ねることができます。
- **「自発的」な AI**: AI はただ答えるだけでなく、`インタラクティブ調査`機能によって「このコマンドを試してみませんか？」と自ら解決策を提案し、実行結果を分析します。
- **「迷わない」UI**: 4つのペインを自由に操れるグリッドシステムにより、ターミナルの作業画面を隠すことなく、AI チャットを最適な位置に配置できます。

## 使い方

### 一般ユーザーの方
最新のWindows用インストーラー（`.exe`）は [Releases](https://github.com/horryworks/HoTTY/releases) ページからダウンロードできます。インストーラーを実行するだけで使い始められます。

### 開発者の方（ビルド手順）

### 事前準備

- [Node.js](https://nodejs.org/) (推奨: LTS バージョン)
- **Windows ビルド環境** (`node-pty` や `serialport` などのネイティブモジュールのビルドに必要):
    - Visual Studio 2022 (「C++ によるデスクトップ開発」ワークロード)
    - **重要**: 個別コンポーネント「MSVC v143 - VS 2022 C++ x64/x86 Spectre-mitigated libs (最新)」が必要です。

### インストール

1. リポジトリをクローンまたはダウンロードします。
2. 依存関係をインストールします:
   ```bash
   npm install
   ```

### アプリケーションの実行

開発サーバーを起動し、アプリを開くには以下のコマンドを実行します:
```bash
npm run dev
```

Windows環境では、付属のバッチファイルも利用可能です:
- `launch_dev.bat`: 開発環境を起動します。
- `launch.bat`: プロダクション用ビルドを実行します（ビルド済みの場合）。

## トラブルシューティング

- **背景画像の読み込み**: カスタム背景が表示されない場合は、ファイルが画像形式（PNG、JPG、SVG、WebP）であることを確認し、設定画面の「Browse」ボタンから正しく選択してください。
- **SSH 接続**: 接続が頻繁に切れる場合は、設定画面で「SSH KeepAlive」の値を調整してください。
- **WSL ターミナル**: WSL接続時にプロンプトが表示されない場合は、対象のディストリビューションが正しくインストール・初期設定されているか確認してください。HoTTYは `node-pty` を利用したネイティブなTTY接続に対応しています。
